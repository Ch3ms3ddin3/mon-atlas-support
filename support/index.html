Assistance Mon Atlas

Pour une question, un dysfonctionnement ou une demande liée à votre compte, écrivez-nous par e-mail. Nous n’offrons pas d’assistance téléphonique.

Demander de l’aide

Envoyez un message à supportmonatlas@gmail.com. Indiquez si possible :

  • le modèle de votre appareil ;
  • la version d’iOS ;
  • la version de l’application Mon Atlas ;
  • une description du problème (ce que vous faisiez, ce que vous attendiez, ce qui s’est produit).

Ces informations aident à reproduire le souci. Elles ne sont pas collectées automatiquement depuis cette page : elles ne partent que si vous les écrivez dans votre e-mail.

Écrire à l’assistance

Suppression du compte

Vous pouvez supprimer votre compte depuis l’application : ouvrez Profil, puis utilisez Supprimer mon compte (uniquement si vous êtes connecté avec un compte e-mail).

Cette action est définitive. L’application appelle alors la fonction de suppression existante : le compte d’authentification est supprimé, et les données cloud qui y sont liées (profil, favoris, préférences, véhicules d’admission temporaire, signalements de contenu) sont effacées avec lui. Les données personnelles de ce compte présentes sur l’appareil sont également effacées localement.

La déconnexion n’est pas une suppression de compte : elle retire les données personnelles de cet appareil, mais conserve le compte dans le cloud. En vous reconnectant, certaines données peuvent être restaurées si elles y étaient synchronisées.

Si vous ne parvenez plus à ouvrir l’application, écrivez à supportmonatlas@gmail.com en précisant l’adresse e-mail du compte concerné.
