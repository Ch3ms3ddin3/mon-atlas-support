Informations légales

Politique de confidentialité

Cette page décrit les traitements de données liés à l’application mobile Mon Atlas, d’après le fonctionnement réel du logiciel et de sa configuration de production.

Dernière mise à jour : 12 octobre 2026

Éditeur et contact

Application : Mon Atlas
Éditeur : Chemseddine Afouf
Contact : supportmonatlas@gmail.com

Données que vous saisissez

Selon l’usage, vous pouvez renseigner : une adresse e-mail et un mot de passe (création ou connexion de compte) ; un prénom, une ville préférée, une langue et un type d’utilisateur ; des véhicules d’admission temporaire (libellé, plaque, pays, dates, notes) ; des filtres de navigation ; un signalement de contenu incorrect ou incomplet.

Le mot de passe n’est pas stocké dans l’application. Il est traité par le service d’authentification (Supabase Auth).

La connexion via Apple ou Google n’est pas proposée dans la configuration de production actuelle.

Compte et données associées (Supabase)

Lorsque le backend est configuré, l’application peut créer une session technique anonyme, puis un compte e-mail si vous vous inscrivez. Un identifiant de compte est alors associé à vos données synchronisées.

Peuvent être enregistrées côté serveur, liées à votre compte :

  • le profil (prénom, ville préférée, langue, type d’utilisateur, et éventuellement un nom affiché ou une URL d’avatar) ;
  • les favoris (type et identifiant d’un lieu, d’un prix ou d’une démarche) ;
  • les préférences (délai des rappels de prière, activation des rappels d’admission temporaire, filtres Explorer) ;
  • les véhicules d’admission temporaire ;
  • les signalements de contenu (entité concernée, type de signalement, texte saisi).

Ces enregistrements sont limités à votre compte par des règles d’accès. La ville choisie automatiquement ou manuellement est stockée comme nom de ville ; le mode « automatique / manuel » de la ville est conservé sur l’appareil et n’est pas envoyé avec le profil serveur.

Localisation

L’application peut demander l’accès à la position lorsque vous utilisez l’app (centrer la carte, météo, horaires de prière, estimation de ville). Elle ne demande pas une localisation permanente ni en arrière-plan.

Les coordonnées GPS ne sont pas enregistrées dans le compte Supabase. Elles sont transmises, le temps de la requête, aux services nécessaires : Open-Meteo (géocodage inverse et météo) et AlAdhan (horaires de prière). Un cache local sur l’appareil peut retenir le dernier résultat météo ou les horaires, indexé par des coordonnées arrondies. Ce cache n’est pas le compte cloud.

Stockage local et cache

Sur l’appareil, l’application conserve notamment le profil, les favoris, les préférences, les véhicules d’admission temporaire, les signalements en attente de synchronisation, l’état d’onboarding, et des caches de météo, d’horaires de prière et de taux de change. Ces caches ont une taille limitée ; aucune durée de conservation en jours n’est définie dans le logiciel.

Un export « Exporter mes données » copie un résumé JSON dans le presse-papiers de l’appareil. Il n’est pas envoyé automatiquement à l’éditeur.

Notifications

Les rappels de prière et d’admission temporaire sont des notifications locales sur l’appareil. L’application n’utilise pas de notifications push distantes dans sa configuration actuelle. Vous pouvez refuser la permission système ou désactiver ces rappels dans l’app.

Calendrier

Si vous choisissez d’ajouter un événement au calendrier de l’appareil, le titre, les dates et la ville sont transmis au calendrier système. Ils ne sont pas envoyés aux serveurs de Mon Atlas pour cet usage.

Recherche vocale sur iPhone

La dictée est facultative et démarre uniquement lorsque vous appuyez sur le bouton microphone de la recherche et autorisez le microphone ainsi que la reconnaissance vocale. Vous pouvez toujours saisir votre recherche au clavier.

Le service de reconnaissance vocale d’Apple transforme votre voix en texte. Atlas demande un traitement sur l’appareil lorsque cette capacité est disponible pour la langue et l’iPhone utilisés. Dans les autres cas, l’audio peut être transmis à Apple pour être reconnu. Ces traitements relèvent du service de reconnaissance vocale d’Apple.

Atlas ne crée ni ne conserve de fichier audio et n’envoie pas votre audio à Supabase. Le texte reconnu remplit le champ de recherche et suit le fonctionnement habituel de la recherche dans l’application. Une session de dictée s’arrête après au plus 30 secondes ; vous pouvez aussi l’arrêter avec le bouton microphone. Les autorisations peuvent être retirées dans les réglages iOS.

Polices et verrouillage biométrique

Les polices de l’interface sont incluses dans l’application ou fournies par le système ; leur affichage ne nécessite pas de téléchargement auprès de Google Fonts.

Si vous activez le verrouillage biométrique, l’authentification est effectuée par le système de votre appareil. Atlas reçoit le résultat de cette vérification et n’accède pas aux données biométriques brutes.

Sentry, publicité et suivi

L’outil de rapport de plantages Sentry est désactivé dans la configuration de production actuelle (aucun identifiant de projet n’est fourni à l’application).

Aucune publicité n’est intégrée. Aucun kit de suivi publicitaire, ni identifiant publicitaire, n’est présent dans l’application.

Services tiers

Dans la configuration de production actuelle, l’application s’appuie notamment sur :

  • Apple Speech — reconnaissance vocale facultative, sur l’appareil si disponible, sinon avec un traitement possible par Apple ;
  • Supabase — authentification, stockage des données de compte listées plus haut, et diffusion d’images éditoriales publiques ;
  • Open-Meteo — géocodage inverse et météo (coordonnées) ;
  • AlAdhan — horaires de prière (coordonnées, date) ;
  • Frankfurter — taux de change EUR/MAD (sans compte utilisateur) ;
  • OpenStreetMap — tuiles de carte (requêtes techniques de téléchargement) ;

Un lien vers Google Maps peut s’ouvrir si vous choisissez d’afficher un lieu dans une application ou un navigateur externe. OSRM et d’autres fonctions expérimentales ne sont pas proposées dans cette configuration.

Conservation et suppression

Le logiciel ne définit pas de durée de conservation en jours ou en mois. Les données de compte sont conservées tant que le compte existe, pour fournir le service (synchronisation, favoris, rappels, etc.).

Depuis Profil, Supprimer mon compte supprime le compte d’authentification. Les données cloud associées (profil, favoris, préférences, véhicules d’admission temporaire, signalements) sont alors supprimées avec le compte. Les données personnelles de ce compte présentes sur l’appareil sont aussi effacées localement. La déconnexion n’efface pas le compte cloud.

Droits et contact

Selon le droit applicable, vous pouvez demander l’accès, la rectification ou la suppression de données vous concernant, ou poser une question sur ces traitements. Écrivez à supportmonatlas@gmail.com. Vous pouvez aussi exporter un extrait depuis l’application et supprimer le compte comme indiqué ci-dessus.
